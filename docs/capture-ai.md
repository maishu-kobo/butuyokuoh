# 写真の見た目から商品を推定する

バーコードは読まない。写真を Cloudflare Workers AI に送り、商品名、ブランド、型番、JAN の候補にする。キーが無いとき、判定できないとき、回数やニューロンの上限に達したときは、商品名の手入力に戻る。

`CAPTURE_ENABLED` と `CAPTURE_AI_ENABLED` が両方 `true` のときだけ呼ぶ。初期値はオフ。キーは `src/lib/capture-secrets.ts` が読む `CLOUDFLARE_ACCOUNT_ID` と `CLOUDFLARE_API_TOKEN` だけを使う。

## 選んだモデル

`@cf/meta/llama-3.2-11b-vision-instruct`

写真20枚の実測（Issue #100）は、この環境に API トークンが無いため未確認。次の表は Cloudflare の公開ドキュメント（料金ページの更新日 2026-10-20、各モデルページ）による。4つとも Vision で、有料プラン必須のモデル一覧には入っていない。無料枠は1日 10,000 ニューロン。

| モデル | 入力ニューロン / 100万トークン | 出力ニューロン / 100万トークン | 画像の渡し方 | ライセンス |
| --- | --- | --- | --- | --- |
| `@cf/meta/llama-3.2-11b-vision-instruct` | 4410 | 61493 | `image` に data URL。テキストが返る | 初回だけ `{"prompt":"agree"}`。未同意はエラー 5016 |
| `@cf/meta/llama-4-scout-17b-16e-instruct` | 24545 | 77273 | チャット。専用の `image` 手順はモデルページに無い | モデルページに同意プロンプトの記載は無い |
| `@cf/google/gemma-4-26b-a4b-it` | 9091 | 27273 | チャット | Meta の同意は不要 |
| `@cf/qwen/qwen3.8-27b` | 40909 | 290909 | チャット。推論の既定が深く、出力が増えやすい | Meta の同意は不要 |

選んだ理由は、4つの中で入力ニューロンが最も少なく、画像を data URL で渡してテキストを受け取る手順がドキュメントにあるため。商品名の正解率は未確認。実測で上位5件の差が1枚以内なら、ニューロンが少ないほうを採る、という Issue #100 の決め方はまだ適用できない。

Meta のライセンスはアカウントで1回。呼び出しが 403 かつ内部コード 5016 のときだけ、写真を付けずに `{"prompt":"agree"}` を送り、同じ判定を1回だけやり直す。同意の文面は利用者には返さない。

## 上限

- 1人につき1分3回、UTC の1日10回。判定の失敗も数える。写真の形式が違うときは数えない。
- 全体で UTC の1日 8,000 ニューロンに達したら、その日は判定を止める。無料枠 10,000 との差は余裕。
- 返事の `usage.prompt_tokens` と `usage.completion_tokens` を料金表で切り上げる。トークン数が無いときは 378 ニューロンとして数える（入力 80,000 トークンと出力 400 トークンの切り上げ。実測ではない）。
- Cloudflare が 429 かつ内部コード 3036（無料枠を使い切った）を返したときも、その日は止める。
- 0時（UTC）に回数とニューロンを戻す。記録はこのプロセスのメモリ上。再起動するとその日のカウントは消える。Cloudflare 側の 10,000 が最終の上限。
- 上限のときは「今日は写真からの自動の判定が上限に達しました。商品名を入れて探してください」。1分の上限だけ「写真からの判定は1分に3回までです。商品名を入れて探してください」。どちらも `fallback` は `manual-entry`。

## ローカルで1枚だけ試す

トークンはリポジトリに置かない。次の値はシェルか、リポジトリの外にあるモード 0600 のファイル（`CAPTURE_SECRETS_FILE`）にだけ書く。

```bash
export CAPTURE_ENABLED=true
export CAPTURE_AI_ENABLED=true
export CLOUDFLARE_ACCOUNT_ID=（32桁の16進数）
export CLOUDFLARE_API_TOKEN=（Workers AI の Read と Edit）
npm run dev
```

会員でログインしたブラウザから、写真を1枚選ぶ。API を直接呼ぶ場合は、ログイン済みの Cookie と、ページと同じ `Origin` を付けて `POST /api/capture/identify` に `photo` というファイルを1つだけ送る。JPEG、PNG、WebP で 5MB まで。30秒で打ち切る。

初回のアカウントでは、同意のリクエストが1回余分に出る。トークンと写真はログに出さない。
